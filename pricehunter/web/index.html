    METHODOLOGY
    
          
    采集与计算口径
    
        
    
      
    
      
    
        
    
          01 / COLLECT
          
    采集
    
          
    通过可插拔 Adapter 接入数据源：内置确定性模拟源、兼容 JSON 的 API 源。真实平台需使用官方开放平台或已授权数据服务。
    
        
    
        
    
          02 / CLEAN
          
    清洗
    
          
    金额、销量单位归一化（万 / 千 / +），剔除标题或价格缺失的记录，并用 IQR × 3 围栏过滤异常价格。
    
        
    
        
    
          03 / DEDUPE
          
    去重
    
          
    标题标准化后生成指纹，跨平台同款合并为一条记录，保留最低价报价，并记录其余平台的可购价格。
    
        
    
        
    
          04 / SCORE
          
    评分
    
          
    性价比 = 46% 价格优势 + 29% 销量热度 + 25% 店铺评分，归一化到 0–100，映射为四级推荐标签。
